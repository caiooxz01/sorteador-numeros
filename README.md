# Sorteador de números

## 📌 Sobre
Projeto utilizado nos cursos de lógica de programação da Alura. Você informa a quantidade de números e o intervalo (de / até), e o programa sorteia números sem repetir. Tem também um botão para reiniciar.

## 🚀 Como usar
Abra o arquivo `index.html` no navegador.
